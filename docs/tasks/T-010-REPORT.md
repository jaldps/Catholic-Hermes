# T-010 · Identificación y atribución de las Biblias · Codex

## Alcance y resultado

Investigación documental de las seis ediciones solicitadas. Se respeta la declaración del dueño, recogida en `T-010.md` y `docs/content/BIBLE-EDITIONS.md` el **15-XI-2026**, de que cuenta con permiso para usarlas. **No se retira ninguna Biblia, no se modifica código o texto bíblico y no se condiciona una publicación a esta investigación.**

Se distingue ese permiso declarado de una licencia pública: encontrar una reserva expresa no demuestra que el dueño carezca de autorización privada. Sí impide describir automáticamente la traducción como «dominio público» o atribuir al MIT del programa los derechos de sus textos. El alcance concreto de las autorizaciones privadas no consta en los archivos consultados; no se inventan condiciones contractuales.
