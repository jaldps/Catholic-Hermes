# T-069 · Capturas reales desde el teléfono del dueño (adb)

- **Asignado:** Hermes (trabaja en el PC del dueño, donde está conectado el teléfono)
- **Estado:** ABIERTO (28-nov) · se repite cada vez que el coordinador lo pida
- **Rama de entrega:** `ext/T-069`, desde `origin/CatholicGPT`

## Por qué

El coordinador trabaja en la nube y no llega al teléfono del dueño. Las capturas reales del teléfono valen más que las renderizadas y son más rápidas. El dueño tiene el teléfono conectado por USB con depuración activada.

## Qué hacer

1. `git fetch origin`. Compila `origin/CatholicGPT` con la clave de la preview:

   ```sh
   ./gradlew --no-daemon -I tools/hermes-preview.gradle :app:assembleDebug
   ```

   Sin tests (regla 11).
2. `adb devices` debe mostrar el teléfono. Instala la APK encima de la que tenga, conservando los datos:

   ```sh
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

3. Abre la app y, en cada pantalla de la lista, haz una captura:

   ```sh
   adb exec-out screencap -p > <nombre>.png
   ```

   Pantallas, primero en **modo Día** y después en **modo Noche** (Ajustes › Apariencia › Modo):
   - `hoy`, `orar`, `leer`, `mi-camino`, `explorar`;
   - `rosario`: abre el Rosario y avanza a la primera Avemaría;
   - `coronillas`: Orar › Otras coronillas, con el catálogo abierto;
   - `padrenuestro`: Orar › Básicas › Padrenuestro;
   - `santo`: Explorar › Santos, la ficha de un santo;
   - `ajustes`: Ajustes › Apariencia.

   Si una pantalla es más alta que la del teléfono, haz una segunda captura tras desplazar (`<nombre>-2.png`).
4. Guárdalas en `docs/tasks/T-069-shots/<fecha>/` como `<nombre>-dia.png` y `<nombre>-noche.png`, reducidas al 50 %. Añade un `README.md` con el modelo del teléfono, la versión de Android (`adb shell getprop ro.build.version.release`) y el commit compilado.
5. Commit «T-069: capturas del teléfono <fecha>» y push a `ext/T-069`. Si no tienes permiso, usa tu fork.

## No hagas

- No cambies código, versiones ni firma.
- No borres datos del teléfono: usa siempre `install -r`.
- No captures pantallas con datos personales del dueño (diario, notas de confesión). Si aparecen, salta esa pantalla.
