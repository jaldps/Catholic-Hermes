- **Asignado:** Codex

Documenta la edición, el editor y la atribución que deba mostrarse. Si encuentras algo que contradiga la declaración, anótalo claramente en el informe.
- **Rama de entrega:** `ext/T-010`
- **Archivo que creas:** `docs/tasks/T-010-REPORT.md`. Es un trabajo de investigación: no cambias código ni datos.

## Contexto

El usuario quiere ofrecer en la app Biblias católicas alternativas, tomadas de `github.com/catholicbibletools/cbt`, carpeta `src/bibles`. Son archivos Go con el texto completo.

El repositorio tiene licencia MIT, pero esa licencia **solo cubre el código**. No establece los derechos de los textos bíblicos.

Regla del usuario: un texto solo se trata como protegido si existe una **reserva de derechos expresa y verificada**. Que aparezca publicado en otro sitio no implica copyright.

## Qué investigar

Ediciones:

| Id | Traducción |
|---|---|
| `es.eldpdd` | El Libro del Pueblo de Dios |
| `es.lbl` | Biblia Latinoamericana |
| `es.lsb` | Identifica cuál es: lee la cabecera de `bible_es_lsb.go` y compara el texto |
| `en.ccb` | Christian Community Bible |
| `pt.bs` | Bíblia Sagrada: identifica la edición comparando el texto |
| `la.nvbse` | Nova Vulgata Bibliorum Sacrorum Editio |

Para cada una, averigua:

1. **Edición exacta:** traductores, editor, año y aprobación eclesiástica (*imprimatur* o conferencia episcopal).
2. **Reserva de derechos.** ¿Hay un «©» o un «todos los derechos reservados» expreso? Indica dónde (portada o página web del editor) y pon la URL o la cita.
3. **Permiso público de uso o redistribución.** Por ejemplo:
   - El Libro del Pueblo de Dios aparece en vatican.va: ¿con qué condiciones?
   - La Christian Community Bible: ¿existe un permiso de distribución gratuita de la Pastoral Bible Foundation o de los claretianos?
   - La Nova Vulgata: ¿qué dice la Libreria Editrice Vaticana?

   Recoge las condiciones de cada permiso: si exige uso no comercial, atribución o prohibe modificar el texto.
4. **Conclusión** para cada edición:
   - `libre`: dominio público o sin reserva;
   - `con permiso`: se puede usar, con las condiciones que indiques;
   - `reservada`: hay reserva expresa y ningún permiso;
   - `dudosa`: no se pudo verificar.

   Añade qué haría falta para poder usarla.

**No inventes nada.** Lo que no puedas verificar, dilo.
