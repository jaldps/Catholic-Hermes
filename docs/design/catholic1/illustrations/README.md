# Catholic1 · Ilustraciones de estados vacíos

Colección original de nueve motivos genéricos para T-068. Cada motivo tiene un SVG maestro editable y un PNG de 512 × 512 px con transparencia, exportado del mismo vector.

- Trazo redondeado de 4 px, sin sombras, texturas ni degradados.
- Marino `#10345C` y un detalle en oro `#DCA83C`.
- Lienzo de 512 × 512; área de diseño nominal de 356 × 356 px centrada, con ajustes ópticos según la silueta.
- Uso previsto: ilustración de 96 dp, según [CATHOLIC1.md](../../CATHOLIC1.md#58-estados). Los colores corresponden a la entrega de T-068; su adaptación a Noche queda para la integración.
