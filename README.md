# Catholic Hermes · Bible data

Per-book JSON files and cross-reference tables (`xref.bin`) for the downloadable Catholic Bible editions of the Catholic Hermes app. Branch kept separate from the app code.

- Source texts: github.com/catholicbibletools/cbt, commit `0568883103855235b4667c8958c5c082db60a420`, converted with `tools/bibles/convert_cbt.py` (CatholicGPT branch).
- Cross-references: OpenBible.info (CC BY 4.0), re-keyed to each edition's numbering with `tools/xref`.
- Editions: en.ccb, en.drbcr, es.eldpdd, es.lbl, es.lsb, pt.bs, la.nvbse. The project owner states these texts are free to use and that permission is held (2026-11-15).
